Up until recently, my code only ever lived on `localhost:3000` — running fine on my laptop, invisible to literally everyone else. Deploying felt like this mysterious final boss step that "real developers" did. Turns out it's a lot simpler than I expected, especially with Vercel.

Here's what I actually did, step by step, in case you're where I was a few days ago.

## Step 1: Push Your Project to GitHub

Before Vercel can deploy anything, your code needs to live on GitHub. From your project folder:

```bash
git init
git add .
git commit -m "initial commit"
git branch -M main
git remote add origin https://github.com/your-username/your-repo.git
git push -u origin main
```

I'd already messed up my git setup once before this, so seeing my files actually show up on GitHub felt like a small win.

## Step 2: Create a Vercel Account

Go to [vercel.com](https://vercel.com) and sign up — the easiest way is to sign up with your GitHub account directly, since it saves you a step later when connecting repos.

## Step 3: Import Your Project

Once logged in:
- Click **Add New → Project**
- Vercel will show a list of your GitHub repos — pick the one you want to deploy
- Click **Import**
